# 项目管理

## 目标与边界

目标：导入三份表格后，可以追溯地查看和统计船检送审、返回、意见回复及关闭情况，保留原台账格式导出。Letter是独立的命名复制流程。

不含：自动登录DNV、自动送审/回复、工程师消息分发、云端业务资料存储。

## 版本与工作流

- `main`：已通过测试、可部署的代码。
- `feature/<描述>`、`fix/<描述>`：日常工作分支，通过PR合入。
- 每个任务在Issue写清问题、验收条件及验证结果。PR关联Issue，说明变更口径与数据兼容性。
- 自动检查必须通过后合入main；main更新自动部署Pages。正式发布打`vX.Y.Z`标签并记录Release。
- 业务数据不得出现在Issue、PR、提交、截图、日志或测试夹具中；复现使用合成资料。

## 验收标准

统计数字能追溯明细；应送=已送+无记录，已送=已返回+待返回，已返回=四种闭环分类，父意见=Open+Closed+其他。跨图意见去重、回复不增意见数。导入失败不覆盖、更新不删除旧数据。原模板导出保持原表数据及顺序。

每轮开发结束更新对应Issue；每个版本更新CHANGELOG与Release。此文档不创建自动提醒，也不代表后台持续运行。
