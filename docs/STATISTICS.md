# 船检统计口径 v0.3.0

确认日期：2026-11-01，Asia/Shanghai。来源是用户确认的传统台账统计框架；截图中的数字不写死到程序中。

## 输入与输出

主输入：文控台账、Documents、Comments。Approval Letter仍是独立文件处理功能，不作为统计必要输入。Comments需要全状态及全版本，不能仅凭文件名推断导出完整性。

首页提供图纸送审/返回/闭环、父意见关闭、批复代码和Open责任方分布。点击数量查看明细，按负责人/图号/图名/批复码筛选，点击图号查看已有意见往来。统计包是完整统计范围的总览CSV、图纸CSV、父意见CSV、口径TXT，查看筛选不会缩小统计包。原格式台账仍由页首导出。

## 应送范围

仅取台账DNV明确勾选的图纸，不受用户关注列表影响。未知标记另提示待确认，空白不自动认定应送。图纸顺序沿用台账。

安全返港排除通过“统计范围”填写明确图号清单，首次默认不排除；不从标题猜测，不擅自排除。保存到`CatalogState.statistics.excludedDrawingNos`，包含在现有备份和台账导入撤销中，重新导入台账保留。清单中图号必须存在于基础台账，只影响统计，原图纸/意见/原格式台账导出均保留。

## 图纸统计

- 应送 = 明确DNV勾选且未排除的唯一图号。
- 已送 = 最新有效Sent Date记录，或没有有效Sent Date时存在Sent/Received状态记录。无日期时保留数据提示。
- 无有效送审记录 = 应送 - 已送，只是导出数据缺少证据，不是断言实际从未送审。Documents未导入显示横线而非未送数量。
- 已返回 = 最新送审记录有Received Date、批复代码或Received状态。有效送审日期优先排序，返回日期仅在相同送审日期时破同序；不借历史旧版本结果替代最新送审。
- 待返回 = 已送 - 已返回。
- 送审率 = 已送 / 应送；退审率 = 已返回 / 已送。

已返回的图纸按顺序分四类，四类合计必须等于已返回：

1. 有未关闭意见：关联父意见有Open，优先于批复码判断。
2. 不适用：无Open且最新批复为FI/DI，不自动归入已闭环。
3. 已闭环：两份导出范围均已确认完整，无保留缺失的图纸/意见/关联，无其他状态意见，Documents的Open字段为0或未提供，且AP/AC对应父意见全部Closed；AP在没有父意见时也可计入。
4. 待确认：其余情况，包括未完整导出、NA等其他意见状态、矛盾Open数、无父意见AC、NP或未知批复码。

图纸闭环率 = 已闭环 / 已返回。不适用和待确认仍在已返回分母内，不通过排除它们提高闭环率。未返回的新版本不计算为已闭环。零分母不显示百分比。

## 意见统计

仅统计关联本次图纸范围的父意见，按项目号+父Comment ID去重。回复流水不增加意见数。跨图纸同一意见只计一次，排除一张图后只要仍关联其他范围内图纸就仍计入。

父意见总数 = Open + Closed + 其他状态。关闭率 = Closed / 父意见总数。Closed状态优先于Closed Date是否为空。未匹配图纸的意见不擅自分配到本部门范围。

Open按当前Action Needed By区分船厂设计、现场、DNV审图、验船师及其他责任方；不将Yard Design直接等同于工程师没回复。Action Required与Important Note类型原样保留，不把全部意见都称作技术待办。回复Last Activity仅称活动时间。

跨负责人图纸共用一个父意见时，可出现在多人的筛选列表，因此各负责人数量不可直接相加当作项目总数。

## 完整性与导出

未确认完整导出时显示“暂定统计”，保留已导出计数但不推断零Open就是闭环。缺失旧数据按已有规则保留并标注，导入日期不作为资料日期；历史样本不是当前实时DNV状态。统计不能证明已分发工程师。

CSV采用UTF-8 BOM、全字段引号及公式前缀保护，可用Excel/WPS打开；不是带样式的新Excel报表。原模板Excel导出功能保持原样。默认统计与人工关注范围用途不同，页首原格式台账仍沿用关注图纸的既有更新范围。

## 验收

应送=已送+无记录；已送=已返回+待返回；已返回=有Open+已闭环+不适用+待确认；父意见总数=Open+Closed+其他状态。数字点开明细匹配，切换指标清除前一指标的查看筛选。32项合成测试覆盖这些关系及导出、备份、范围保留。桌面1440px和窄屏390px实浏览器已验证，真实移动设备未验证。
