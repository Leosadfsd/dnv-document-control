# 未闭环意见处理与导出 v0.4.0

## 当前工作流

Comments导入后即可查看。导入台账后默认看本台账关联的Open父意见；未匹配图纸可切换查看，全项目范围需主动选择。台账全部图纸可在图纸查询中按原顺序查看，不受DNV勾选及关注列表限制。

每个项目+主Comment ID只显示一次。关联多个图纸时都保留，不重复计数。Closed及NA等其他父状态不加入未闭环工作清单。主意见始终在完整往来首位，子消息使用现有数值顺序；缺少或重复顺序时提示核对。

## 最近一轮与当前回方

将连续同方回复组成一轮：Yard Design/Yard Site为船厂侧，Approval Expert/NB Surveyor为船检侧，其他角色保留原文。主意见本身不算船检后续回复。分别展示双方最近一轮的全部消息，未做技术总结或改写。界面长文可展开，导出始终保留全文。

当前回方取主意见Action Needed By：Yard Design→我方设计，Yard Site→船厂现场，Approval Expert/NB Surveyor→船检，其余→待确认。缺失主/子消息或关联时保留旧内容并归待确认，不根据最后发言人猜回方。来源范围不完整时提示“所导出范围”，不声称往来完整或全部闭环。

## 两类Excel

汇总Excel默认导出当前筛选；勾选后只导出筛选内勾选的主意见。按负责人、台账顺序和意见编号排列，未分配负责人放末尾；负责人筛选不丢弃同一主意见的其他关联图纸。预览明确主意见与图纸数量。

按图回复表按选择范围内的实际关联分组，每图一个Excel。保留主意见及全部已导入子消息，使用船检意见/角色、船厂回复/角色、当前状态/回方及附件/提示的回复表结构，再留下一轮船厂回复空白行。没有图号关联的记录另附“待匹配图纸的意见.xlsx”。工程师姓名和图名可在导出前补充，只影响本次文件。

文件名为“图号-图名-负责人-DNV.xlsx”，非法文件名字符替换，大小写冲突自动增加序号，不能覆盖。没有负责人/图名的使用明确待补占位，不能虚构。ZIP含导出说明，说明来源、范围、时间和无图号项。

Excel使用11号字体、固定合理列宽、顶部对齐及自动换行，行高随内容增加，充分使用Excel单行409磅的高度上限；超过上限才续行，续行重复识别号。不写可执行公式。冻结表头及识别列，汇总支持筛选；设置打印区域、重复前6行、A3横向一页宽，多页高，不强压整张表到一页。

## 未来整合接口

`src/module.ts`为可复用入口，暴露纯数据整理及导出函数，不导入UI、IndexedDB或应用Shell。

- `buildOpenCommentCases({catalog,comments})`返回主意见、完整消息、双方最近一轮、图纸关联、回方及数据提示；catalog可为空。
- 导出器接收这些case、项目/来源元数据和可选图名/负责人修正，不读取页面状态或数据库。
- 船东工具共享基础资料时通过适配器将其图号字段映射到drawingNo，保持源项目和系统边界；DNV意见及批复代码仍保留自身语义。

原schema v1和数据库版本不变，不迁移或删除旧数据。未来统一工具直接复用接口，不从业务Excel反向还原意见数据库。

## 验证边界

合成测试覆盖连续回复、角色映射、跨图去重、未匹配项、Closed/其他状态、缺失记录、长文本续行、空白待填行和文件名。浏览器验证Comments单独导入、三表关联、范围/负责人筛选、勾选/两类导出、刷新及390px布局；同一流程未观察到业务上传请求。

两类Excel已用独立渲染器检查。合成回复表在WPS直接打开，无修复提示；打印对话框可打开，但自动控制无法继续，原生打印预览及实际纸张输出尚未完成验收。
